# Milestone 3: Take Checks Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every take gets a verdict within seconds (`keep`, `retake` or `listen`, with reasons), in the window and through `takewise check`, and export adds word times to the manifest.

**Architecture:** Pure logic in `takewise-core`: text normalization and word alignment, the verdict rules, and building the `checked` event from an `Analysis` plus an optional transcript. Transcription sits behind a `Transcriber` trait; the real one converts the take to 16 kHz with `ffmpeg` and runs `whisper-cli` with full JSON output. The window runs checks on a background thread after each commit; the CLI runs them on demand.

**Tech Stack:** Rust 1.99.0, existing crates; runtime `whisper-cli` (Homebrew `whisper-cpp` 1.9.5) and `ffmpeg`; model `ggml-large-v3-turbo.bin` in `$TAKEWISE_MODELS` or `~/.local/share/takewise/models` (already downloaded on Niklas's Mac).

**Spec:** `docs/design.md` sections "Checks" and "The ledger" (`checked` event), "Export" (word times).

## Global Constraints

- Transcription never receives the script as a prompt.
- Verdict rules in exactly the design's order, first match wins: no speech → `retake`; clipping → `retake`; missing or extra words → `retake`; overrun > 0.25 s or early start > 0.3 s → `retake`; transcription failed or unavailable → `listen`; only substitutions → `listen`; otherwise `keep`.
- Early start is measured from the first transcribed word when transcription succeeded, otherwise from the energy speech start. Overrun is always from the energy speech end.
- A check never blocks recording or choosing; a failed check is a `listen` verdict with a reason, not an error dialog.
- `checked` events carry the snapshot they were computed against and `checker` = `"takewise <version> whisper <model file name>"`.
- Real takes from Niklas are used read-only for evaluation and never copied into the repository.

## Review Focus

1. **Contractions, numbers and punctuation** ("there's", "link's", "1867", "open-source") → normalization treats spoken and written forms as equal, so they do not produce false `retake`s. (Task 1 tests.)
2. **Whisper hallucinating text in silence** (for example "Thank you." in the tail) → words outside the energy speech range ± 0.3 s are dropped before alignment. (Task 3 test `drops_words_outside_speech`.)
3. **whisper-cli missing, model missing, or a crash** → verdict `listen` with reason code `words-not-checked` and the error text, never a panic. (Task 3 tests.)
4. **A check finishing after the line was edited** → the event carries the old snapshot, so the fold shows it as stale; nothing overwrites newer state. (Task 4 test `check_racing_an_edit_is_stale`.)
5. **Very short lines** ("Nobody misses a birthday.") → one substitution yields `listen`, a missing word `retake`; tolerances do not divide by the word count. (Task 2 tests.)

**Interfaces:**

### Task 2: Verdict rules

**Files:** Create `crates/takewise-core/src/check.rs` (unit tests inside).

**Interfaces:**
- Consumes: `Analysis` (speech.rs), `align`, `Snapshot`, `Checked`, `Verdict`, `Reason`.
- Produces: `pub enum Transcript { Words(Vec<Word>), Failed(String) }`; `fn build_checked(snapshot: &Snapshot, line_offset_s: f64, analysis: &Analysis, transcript: &Transcript, checker: &str) -> Checked`. Film-relative quantities: speech start in line time = `line_offset_s + speech.0`, compared with 0 (the line's start); overrun = `line_offset_s + speech.1 − (snapshot.end − snapshot.start)`. Reason codes: `no-speech`, `clipping`, `missing-words`, `extra-words`, `overrun`, `early-start`, `words-not-checked`, `possible-mishearing`. `Checked.speech` stays in source seconds (as milestone 1 defined).

### Task 4: `takewise check`, window verdicts and manifest words

**Files:** Modify `crates/takewise/src/cli.rs` (`check`, `doctor`), `crates/takewise/src/window/{recorder,takes,mod}.rs`, `crates/takewise-core/src/export.rs`; Create `crates/takewise-core/src/run_check.rs`.

**Interfaces:**
- Produces: `fn check_take(dir: &Path, take: &TakeRef, transcriber: &dyn Transcriber) -> Result<Checked>` (reads the take and its `recorded` event, takes the snapshot from the current script at start, runs `analyze` and `transcribe`, appends `checked` under the lock). `takewise check <dir> [--line ID] [--take N] [--stale-only]` (default: all takes without a matching check), prints verdicts, `--json`; exit 0 even when verdicts are `retake` (a verdict is not an error), exit 2 on setup errors. `doctor` runs a 1 s silent transcription to prove whisper works.
